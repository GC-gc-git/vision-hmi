0开课前：5 分钟想清楚「级别」到底解决什么问题

先别写代码。你现在的日志只有一档——只要调用了写日志的方法就往文件里塞一行。这在两种情况下都会出事：

  • 全都记：程序里一句「相机已打开」都写进去，一天下来日志几百 MB，硬盘遭殃，真要查问题时翻日志翻到崩溃。
  • 全不记：只记异常，那程序「今天效率特别低」这种怪现象，日志里一个字都没有，因为你只记了错误。
核心认知：日志级别不是「三种不同的日志写法」，而是同一份日志，按重要程度分流。级别决定的是「这条信息值不值得占磁盘」。

2加日志级别（35 分钟）

2.1 先定接口（你自己写，我给签名）

三个方法，命名保持一致：

public static void LogDebug(string msg)
public static void LogInfo(string msg)
public static void LogError(string whereText, Exception ex)
设计题（先自己想 2 分钟再往下看）：为什么 LogError 多了 whereText 参数，而 LogInfo / LogDebug 没有？

参考答案：因为异常需要知道来源，流程日志不需要。「开始检测」这句话本身就说明了是哪一步；「空引用」不告诉你来源，你根本不知道是相机、标定还是通讯出的问题。

要点：接口设计要按信息的实际需要来，不是为了统一而统一。三个方法签名不一样不是设计缺陷，是对的。硬塞成 Log(string where, string msg, Exception ex = null) 反而让调用方每次都得填一个用不上的参数。

2.2 定义级别枚举

新建 LogLevel 枚举，数值顺序必须是这样：

public enum LogLevel { Debug = 0, Info = 1, Error = 2 }
为什么 Debug 是 0？因为枚举要能直接比较大小，「重要程度」是递增的：Debug 最不重要，Error 最重要。这样你就能用一行判断过滤：
if (level < MinLevel) return;
写成 Error = 0, Debug = 2 就得反着比，逻辑会绕。这个顺序在单元 2C 加锁、单元 3 错误码时还会用到。

2.3 加「最低级别开关」

加一个静态字段，作为那个「可拧的旋钮」：

public static LogLevel MinLevel = LogLevel.Debug;   // 默认全开

它的作用：级别低于 MinLevel 的日志，直接 return，不写文件。

MinLevel =DEBUGINFOERROR文件大小
Debug✓ 写✓ 写✓ 写最大
Info✗ 丢弃✓ 写✓ 写中等
Error✗ 丢弃✗ 丢弃✓ 写最小
被丢弃 ≠ 没发生。它发生了，只是「不值得占磁盘」。现场排查时把旋钮拧回 Debug 重跑一次就有了。

今天的方案有个明确缺点，你要记住：改级别要重新编译。客户现场想临时关掉 DEBUG，做不到。这不是 bug，是留给单元 5 的引子——那时讲 Log4Net 的配置文件外置，你就有对比了。记到任务卡的「坑」里，面试时讲「我知道自己方案的局限、下一版怎么改」比讲「我用了 Log4Net」值钱得多。

2.4 三个入口共用一个私有写入方法

别犯这个错：不要在 LogDebug / LogInfo / LogError 里各写一遍格式化逻辑。三份重复代码意味着以后改格式要改三个地方，漏一个就日志格式不一致。三个公开方法只做「判断级别 + 组织内容」，然后调用同一个私有方法去真正写文件。

3统一记录格式（20 分钟）

你昨天的格式是：

[2026:10:24 21-10-50][button1]System.NullReferenceException: ...

加了级别之后要变成：

[2026-10-25 19:20:33.127][ERROR][button1]System.NullReferenceException: ...
   在 w1_异常体系.Form1.button1_Click(...) 位置 ...\Form1.cs:行号 29
改动为什么
加 [ERROR] 级别段一眼分清这条是流程还是故障
时间加毫秒 .127多线程下毫秒时间戳能看出是不是同一时刻写的——这正是单元 2C 排锁问题的关键证据
yyyy:MM:dd → yyyy-MM-dd分隔符统一用短横线，更规范
堆栈单独占行你昨天已经做到了（{ex} 的 ToString 自带换行），保持
时间为什么必须带毫秒？单元 2C 你会开 3 个线程各写 50 条。如果丢行了，你需要知道「哪几条是同一瞬间写的」才能看出交错。秒级时间戳全一样，毫秒级才有区分度。现在多写的这 3 个字符，是给未来的自己省 2 小时。
